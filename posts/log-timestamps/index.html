Reconciling time zones in logs

A convention for ordering events when log sources use different time zones.

loggingtimestampsforensics

On this page

  • The problem
  • Example
  • Limitations

The problem

Two systems can record the same instant in different time zones. Keeping the original timestamps lets readers check the conversion.

Example

Source Timestamp UTC
Workstation 2026-11-02T14:00:00+07:00 2026-11-02T07:00:00Z
Service 2026-11-02T07:00:00Z 2026-11-02T07:00:00Z

Limitations

Time zone conversion makes the timestamps comparable. When analyzing real logs, check clock skew and the precision of each source as well.
