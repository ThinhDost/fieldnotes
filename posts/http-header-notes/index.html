Reading an HTTP response header by header

Identify the headers and body of an HTTP response and record the details that matter in a web writeup.

httpheadersweb

On this page

  • Context
  • Sample response
  • Recording observations

Context

An HTTP response contains the request outcome, metadata, and a body. This writeup uses a simulated response to demonstrate how to document each part.

Sample response

Header Meaning in this example
Content-Type The body is UTF-8 text.
Cache-Control The response instructs caches to avoid storing it.
Content-Length The body is five bytes long.

Recording observations

Preserve the original response in a code block, then explain each detail below it. Label any shortened or simulated data alongside the example so readers can judge its limits.
