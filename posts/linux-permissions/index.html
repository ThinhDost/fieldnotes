Reading Linux file permissions

Read the permissions granted to the owner, group, and other users of a sample file.

linuxpermissions

On this page

  • Goal
  • Example
  • Verify the result

Goal

Read the permission groups on a sample file and relate them to their octal representation.

Example

An example result is -rw-r--r-- 644 notes.txt. The owner can read and write the file. The group and other users can read it.

Verify the result

Compare each group of three characters with the read, write, and execute values. The output depends on the permissions of the file you inspect.
